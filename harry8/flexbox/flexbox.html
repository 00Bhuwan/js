to initialize a flexbox use e.g .div_class{ display: flex; } [o o | 0 0] the outer square bracket indicate flex container o and 0 indicate flex items there are two axis one across all items in flex container another cross axis: mostly vertical axis flex-direction property = defines the direction toward which items are laid e.g row, row-reverse, column, column-reverse flex property for the parent i.e flex-container 1. flex-wrap: can be wrap, nowrap, wrap-reverse 2. justify-content: defines alignment along main axis 3. align-items: defines alignment along cross axis 4. align-content: align a flex container's lines when there is extra space in cross axis flex property for the children i.e flex items 1. order: controls the order in which the items appear the flex container 2. align-self: allows default alignment to be overridden for the individual flex items 3. flex-grow: defines the ability for a flex item to flex-grow 4. flex-shrink: specifies how much a flex item will shrink relative to the rest of the flex items
